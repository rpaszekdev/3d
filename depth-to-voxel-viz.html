Depth→Voxel Visualizer

16

Algorithm Steps

1 Source Scene

A simple 3D room with colored objects. This is the "ground truth" — what a photo of a room represents.

2 Depth Map

A monocular depth model (MiDAS/Depth Anything) estimates distance from camera for each pixel. Brighter = closer.

Color
Depth
3 Back-Projection

For each pixel, cast a ray from the camera. Use the depth value to find the 3D point. The ray stops where the surface is.

4 Voxelization

Quantize each 3D point into the nearest grid cell. Assign the pixel's color (mapped to 16-color V4 palette).

5 V4 Code

Greedy box merge: combine adjacent same-color voxels into B commands. Output is ready for your DSL renderer.
