The gap is enormous. AI models that can write poetry and prove theorems perform at random chance on tasks a child can do — like mentally rotating an object or answering "what's to the left of the blue box?"

The Insight

LLMs are text machines. They can't see images. But they're extremely good at reading structured data — tables, code, matrices.

What if we translated 3D scenes into structured text?

Instead of giving AI vision, we give it a text-based camera that converts 3D geometry into grids of numbers it can already understand.

This is the Mind's Eye — a system where an LLM:

  • Writes 3D scenes in a simple voxel language (VOXI)
  • Sees them rendered as ASCII depth maps (numbers 0–9)
  • Verifies its spatial reasoning by inspecting the renders
  • Revises and iterates until confident

What the numbers mean

Camera  ──────────────→  Scene

  ║
  ║ center ray ─── 1 ───→ ● hits nose
  ║
  ║ mid ray ────── 3 ───────→ ● hits middle
  ║
  ║ edge ray ──── 5 ──────────→ ● barely grazes
  ║
  ║ miss ray ──── . ─────────────→   (nothing)
  ║

1 at the center = closest point (the "nose").
Numbers increase toward the edges as the surface curves away from the camera.

Same object, different angle = different depth map. That's how you get 3D understanding from 2D views.

Camera Commands — How the LLM Explores

LOOK

View from any of 6 directions:
front, back, left, right, top, bottom

Like walking around a sculpture

ZOOM

Crop to a spherical region around a point, with 3 orthogonal views

Like leaning in to inspect a detail

SLICE

Cut through the scene at any plane, showing actual colors

Like an MRI scan — reveals internals

WHAT

Click a pixel → get 3D coordinate, color, depth, and which source line made it

Traces a ray back to source code

WIDE

All 6 views at once, arranged like an unfolded cube

Complete overview in one shot

PAINT / ERASE

Edit voxels through the camera view — place or remove material

Direct manipulation through text

Nobody else does the closed loop:

Scene → depth text → LLM reads → LLM reasons → LLM acts → verify → repeat

The research community (VoxPoser paper, 2023) recommends this architecture as theory. We built it.

Four unique contributions:

  • Text-based 3D perception — depth matrices as text, no vision model needed
  • LLM-controlled camera — ZOOM, SLICE, WHAT: bidirectional inspection loop
  • Source tracing — WHAT command bridges pixel → 3D coord → source line of code
  • No GPU constraint — entire system runs as pure text processing

Live Demo

Run these in the terminal to show the system working:

1. Create a scene and see it from the front

echo "LOOK front" | node minds-eye.js --code "V 16 16 16
S 8 8 8 6 7"

Shows an orange sphere with depth gradient — 1 at center, 5 at edges

2. Slice through it like an MRI

echo "SLICE y=8" | node minds-eye.js --code "V 16 16 16
S 8 8 8 6 7"

Shows a circular cross-section — all 7s (orange), proving it's solid

3. Click a pixel to trace it back to source code

echo "WHAT front 8 7" | node minds-eye.js --code "V 16 16 16
S 8 8 8 6 7"

Reports: 3D position (8,8,2), color orange, depth 2, created by line "S 8 8 8 6 7"

4. Open the 3D renderer

cd voxi-reasoning && node render-service.js &
open http://localhost:3334

Full 3D WebGL view you can rotate with the mouse

Novel: No vision model needed — the entire loop is text in, text out
