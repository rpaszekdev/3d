Research Motivation

Large language models (LLMs) have achieved remarkable performance across many reasoning tasks, yet they consistently fail at spatial reasoning. On the ARC-AGI-2 benchmark, frontier models including Claude Opus and GPT-4o score between 2% and 5%, while humans achieve over 80% (Chollet, 2025). Mental rotation tasks reduce multimodal LLMs to random chance (Srivastava et al., 2025), and perspective-taking accuracy for GPT-4o is only 27.5% compared to human intuitive performance (Yang et al., 2025). This gap persists despite massive increases in model scale, multimodal training, and chain-of-thought prompting.

From a societal perspective, spatial reasoning failures have real consequences: autonomous vehicle misclassifications have caused serious accidents, warehouse robots fail on 35% of manipulation tasks, and no Level 4/5 autonomous surgery has been deployed due to spatial reasoning limitations in soft tissue (Yang et al., 2025). Scientifically, this failure is puzzling because LLMs excel at other forms of reasoning — mathematical proofs, code generation, logical deduction — but collapse when reasoning requires understanding 3D structure.

Current approaches to improving LLM spatial reasoning focus on adding vision modules: SpatialVLA embeds depth as features in vision-language models, and DepthVLA adds depth streams to multimodal architectures. However, these approaches increase model complexity and remain tied to visual input. An alternative, under-explored hypothesis is that LLMs may already possess sufficient reasoning capability, but lack an appropriate representation format for spatial information. Larkin and Simon (1987) demonstrated formally that diagrams can make previously intractable problems trivially solvable — not by adding new information, but by making spatial relationships computationally accessible.

Research Question

To what extent do text-based depth representations, generated from a voxel domain-specific language, improve large language model performance on spatial reasoning tasks where current models score below 50%?

Background

The theoretical foundation for this work comes from Larkin and Simon (1987), who proved that the computational difference between sentential and diagrammatic representations is not informational but structural: diagrams group spatially related information together, enabling perceptual operations that are computationally expensive in text. This principle suggests that converting spatial problems into structured, spatially-organized text could provide similar benefits for LLMs.

Recent work has begun exploring spatial intermediates for LLM reasoning. The Visualization-of-Thought (VoT) framework demonstrated that generating spatial intermediates (ASCII-like grids) during reasoning improved LLM performance on navigation and tiling tasks (Wei et al., 2024). The Whiteboard-of-Thought (WoT) paradigm showed that a draw-render-perceive loop — where models generate visual code, render it, and interpret the output — improved spatial accuracy over pure text reasoning (Xu et al., 2024). VoxPoser used LLMs to generate Python code that filled 3D voxel grids with affordance values for robot planning, achieving zero-shot generalization (Huang et al., 2023).

However, no existing system implements a complete closed loop where an LLM writes 3D spatial code, receives text-based depth feedback from a raycasting camera system, verifies its reasoning against the rendered output, and iteratively revises — all without any vision model. The Mind's Eye system, which this proposal aims to evaluate, implements precisely this architecture using VOXI, a voxel description language, paired with a text-based raycaster that produces ASCII depth maps (digits 0-9 representing distance from camera). Methods

Experimental Design

This study employs a 2×2 factorial design with two independent variables: (a) representation type (natural language only vs. natural language augmented with text-based depth matrices) and (b) model capability level (high-capability model: Claude Sonnet vs. lower-capability model: Claude Haiku). The dependent variable is task accuracy (percentage of correctly answered spatial reasoning questions).

Datasets

Three existing benchmarks will be used. First, the SpartQA dataset (Mirzaee et al., 2021), consisting of multi-hop spatial reasoning questions derived from natural language scene descriptions (e.g., "What is the relation of block A to block C?" requiring transitive inference through block B). Twenty tasks of varying difficulty will be sampled. Second, the CATER video benchmark (Girdhar & Ramanan, 2020), providing real-world video scenes requiring 3D spatial understanding; five tasks involving object counting, motion tracking, and occlusion detection will be used, with depth matrices extracted at 20×20 resolution using Depth Anything V2. Third, thirty automatically generated VOXI scenes (16×16×16 grids, seed=42) with five question types: collision detection, relative position, motion direction, object count, and closer-to-camera judgments.

Feature Extraction

For the depth-matrix condition, the Mind's Eye system converts spatial information into structured text through orthographic raycasting. For each scene, six depth maps (front, back, left, right, top, bottom) are generated as character grids where each cell contains a digit 0-9 representing normalized depth. For CATER video, monocular depth estimation (Depth Anything V2) produces per-frame 20×20 depth matrices quantized to the same 0-9 range. The control condition receives only the original natural language descriptions or VOXI source code without depth rendering.

Procedure

Each model-condition combination will be tested on all tasks. For each task, the LLM receives the spatial problem description and (in the depth condition) the corresponding depth matrices. The model produces an answer, which is compared against the ground truth. No iterative refinement is permitted during benchmarking — each answer must be given in a single pass to ensure controlled comparison.

Statistical Analysis

A two-way analysis of variance (ANOVA) will test the main effects of representation type and model capability, as well as their interaction. Given preliminary results suggesting that the tool helps high-capability models but may hurt lower-capability ones, the interaction effect is of particular theoretical interest. Post-hoc comparisons using Tukey's HSD will identify significant pairwise differences. Additionally, accuracy will be broken down by task type (collision, position, motion, count, occlusion) to identify which spatial reasoning subtasks benefit most from depth representations. Effect sizes (Cohen's d) will be reported for all significant comparisons.
