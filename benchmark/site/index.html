What is SSL?

SSL (Spatial Sketch Language) is a purely numeric format for describing 3D scenes. Each line defines a shape with its type, position, size, and color — all as numbers. It's designed for LLMs to generate without ambiguity. 

P1                          -- isometric mode
0 150 0 150 100 5 100 7     -- box: table top (orange)
1 200 70 200 15 15 0 1      -- sphere: red ball on table
2 180 5 180 8 60 0 9        -- cylinder: table leg (gray)

Why This Benchmark?

Existing LLM benchmarks test text, code, and math — but not 3D spatial reasoning. Can a model understand that a chimney goes on top of a roof? That wheels go under a car? That a spiral staircase needs consistent spatial progression?

SSL makes this testable: the output is a compact numeric format that renders to a 3D scene. We can see exactly how each model reasons about space.

Methodology

  • Each model receives the same system prompt with SSL format specification and examples
  • 50 prompts across 5 tiers of difficulty (basic objects to abstract concepts)
  • Generated SSL is validated and rendered to PNG via Three.js (headless Playwright)
  • Each render is scored by Claude Sonnet on recognizability, aesthetic quality, and creativity (1-10)
  • Failed generations get one retry with error feedback

Scoring Dimensions

  • Recognizability (R): How clearly does this depict the prompted subject?
  • Aesthetic (A): Visual quality, proportions, spatial arrangement
  • Creativity (C): Use of shapes, clever composition, detail beyond minimum
  • Total: Average of all three dimensions

Tiers

  • Tier 1 — Basic (10 prompts): Simple objects — snowman, rocket, house
  • Tier 2 — Intermediate (10 prompts): Multi-part objects — car, castle, guitar
  • Tier 3 — Complex (15 prompts): Detailed assemblies — locomotive, cathedral, pirate ship
  • Tier 4 — Scenes (10 prompts): Multi-object environments — park, city, farm
  • Tier 5 — Abstract (5 prompts): Conceptual challenges — DNA helix, fractal tree, impossible triangle

Run It Yourself

git clone <repo-url>
cd spatial-reasoning-dsl/benchmark
cp .env.example .env   # add your API keys
npm install
npm run pipeline        # generate → render → evaluate → aggregate

You can run individual steps, filter by model or tier, and adjust concurrency. See the README for full CLI options.
